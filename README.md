# CHUNITHM 历代定数档案

[打开日服谱面矩阵](https://unknnownnn003.github.io/chuni-const/)

查阅 CHUNITHM 日服从初代到 MATE 的谱面定数。每列是一个版本，每行是一张谱面。WORLD’S END 显示属性和星数。

- 按 `/` 搜索曲名、曲师或谱师，也可以按难度、分类、版本和定数范围筛选。
- 拖动矩阵浏览。用双指捏合、`Ctrl` + 滚轮或矩阵下方的按钮缩放。
- 点击曲名或曲绘可查看谱师和各版快照。按 `Esc` 关闭详情。

数据覆盖至 2026 年 10 月 8 日的 MATE 快照。曲绘和版本标识的权利归各自权利人所有。
